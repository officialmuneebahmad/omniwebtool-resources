# OmniWebTool

> Free, private, GDPR-compliant digital toolkit 
> for European users.

**[omniwebtool.com](https://omniwebtool.com)**

---

## What is OmniWebTool?

30+ browser-based tools built specifically for 
European users. Everything runs locally in your 
browser — no file uploads, no server processing, 
no account required.

## Tools Available

**PDF Tools**
- PDF Compressor, Merger, Splitter
- PDF to Word, Excel, JPG converter
- OCR PDF, Sign PDF

**Image Tools**  
- Image Compressor, Resizer
- Background Remover
- Format Converter (JPG, PNG, WebP, SVG)

**Calculator Tools**
- VAT Calculator (all EU-27 countries)
- BMI, Mortgage, Age, Percentage
- Compound Interest, Tip, Discount

**Developer Tools**
- JSON Formatter, Base64 Encoder
- UUID Generator, Regex Tester
- CSS Minifier, URL Encoder

**Security Tools**
- Password Generator
- Hash Generator (MD5, SHA256)
- Password Strength Checker

**Text Tools**
- Word Counter, Case Converter
- Lorem Ipsum Generator
- Text Compare, Morse Code

## Key Features

- ✅ 100% client-side processing
- ✅ No file uploads to servers
- ✅ No account required
- ✅ No watermarks or usage limits
- ✅ GDPR compliant (Cookiebot CMP)
- ✅ Available in EN, DE, FR, ES
- ✅ Mobile friendly
- ✅ Free forever

## Tech Stack

- **Framework**: Next.js 14 (App Router, SSG)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **i18n**: next-intl (4 languages)
- **Deployment**: Cloudflare Workers + OpenNext
- **Consent**: Cookiebot CMP (IAB TCF v2.2)
- **Analytics**: Google Analytics 4
